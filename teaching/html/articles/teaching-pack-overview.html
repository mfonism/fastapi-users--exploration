Teaching Pack: Explore Auth API

This folder turns the current repository into a beginner-friendly rebuild plan. It treats the current codebase as the final target state and ignores existing commit history.

Use these documents when preparing a live workshop, classroom sequence, or conference tutorial.

Task Files

The tasks directory contains one Markdown file per task, suitable for copying into GitHub Issues, Linear, or another task-management service.

Each task includes:

  • title
  • rich description
  • time estimate
  • difficulty
  • parent epic
  • sibling tasks
  • blocking tasks
  • tasks it blocks
  • files created or modified
  • implementation objective
  • acceptance criteria
  • suggested commit message

Start with tasks/README.md for the task index and dependency map.
