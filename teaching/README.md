# Teaching Pack: Explore Auth API

This folder turns the current repository into a beginner-friendly rebuild plan.
It treats the current codebase as the final target state and ignores existing
commit history.

Use these documents when preparing a live workshop, classroom sequence, or
conference tutorial.

## Documents

| File | Purpose |
|---|---|
| [01-project-summary.md](01-project-summary.md) | High-level project, technologies, and learning goals. |
| [02-final-architecture.md](02-final-architecture.md) | Final folder structure, module responsibilities, and request/data flow. |
| [03-infrastructure-first-setup.md](03-infrastructure-first-setup.md) | Early setup path for scaffolding, dependencies, config, DB, tests, and tooling. |
| [04-recommended-teaching-sequence.md](04-recommended-teaching-sequence.md) | Ordered rebuild sequence with small commits and learning goals. |

| [06-teaching-notes.md](06-teaching-notes.md) | What to explain, common mistakes, checkpoint questions, and stretch ideas. |
| [07-risk-review.md](07-risk-review.md) | Complex parts to simplify, defer, or hide behind helpers. |
| [08-code-walkthrough-snippets.md](08-code-walkthrough-snippets.md) | Representative code skeletons for live teaching. |

## Task Files

The [tasks](tasks) directory contains one Markdown file per task, suitable for
copying into GitHub Issues, Linear, or another task-management service.

Each task includes:

- title
- rich description
- time estimate
- difficulty
- parent epic
- sibling tasks
- blocking tasks
- tasks it blocks
- files created or modified
- implementation objective
- acceptance criteria
- suggested commit message

Start with [tasks/README.md](tasks/README.md) for the task index and dependency
map.
